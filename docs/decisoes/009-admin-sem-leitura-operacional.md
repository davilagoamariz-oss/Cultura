# 009. Admin da empresa não lê dados operacionais sem vínculo

**Contexto.** O admin gerencia a estrutura (unidades, setores, talhões, vínculos, ajustes), mas nem
todo admin precisa ver avaliações e decisões.

**Decisão.** Menor privilégio: ler avaliações, plantas e decisões exige vínculo ativo no setor (dono
da avaliação, agrônomo ou gerente). O admin que queira ver se vincula ao setor. O admin da plataforma
(dono do sistema) gerencia empresas e catálogo, mas não lê dados de nenhuma empresa.

**Consequências.** Nenhuma conta, por mais poderosa que seja, enxerga a operação de todos os setores
por padrão. Um comprometimento de conta de admin expõe menos.
